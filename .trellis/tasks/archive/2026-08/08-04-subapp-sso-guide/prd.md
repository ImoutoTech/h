# 子应用页展示 SSO 接入说明

## Goal

让需要接入统一登录的子应用开发者能直接在前端子应用管理页查看、分享和保存现有 OIDC/SSO 接入说明，不必进入后端仓库寻找文档。

## Background

- 接入说明当前位于后端仓库 `docs/third-party-oidc-integration-guide.html`，是可独立打开的完整 HTML 文档。
- 前端是独立的 `safe-house` Vue 3 应用；子应用列表页位于 `src/views/user/pages/user-app.vue`。
- 页面头部已有“创建子应用”按钮，前端使用 Naive UI，并已配置 `@vicons/ionicons5` 图标库。

## Requirements

- 将现有接入说明作为前端可公开访问的静态 HTML 资源，由前端构建产物提供稳定 URL。
- 在“创建子应用”按钮左侧增加一个仅图标的圆角矩形说明入口按钮，并提供可理解的悬停提示和无障碍标签。
- 点击入口后打开覆盖当前页面的大尺寸悬浮模态框，在模态框主体内渲染完整 HTML 文档。
- 模态框底部提供两个明确操作：复制当前说明文档的绝对访问链接、下载原始 HTML 文件。
- 模态框正文与底部操作栏之间保留清晰的上方间距，操作栏不能紧贴预览内容。
- 复制成功或失败应有可感知反馈；下载文件名应稳定且能体现文档用途。
- 模态框在桌面端尽量利用可视区域，在移动端仍可正常关闭、预览和操作，工具栏不得遮挡正文。
- 入口不依赖“新建子应用”权限；能进入子应用页面的用户均可查看接入说明。
- 不修改接入说明正文内容，不新增后端 API，也不引入第三方依赖。
- 迁移完成后删除后端仓库中的原始 HTML；前端静态资源成为唯一维护来源，避免多份内容漂移。

## Out of Scope

- 将说明内容改写为 Vue 组件或 Markdown。
- 在线编辑、版本历史、打印、全文搜索等文档管理能力。
- 修改 OIDC/SSO 协议、后端接口或子应用创建流程。

## Acceptance Criteria

- [ ] 子应用页面中，圆角矩形说明图标按钮紧邻并位于“创建子应用”按钮左侧。
- [ ] 点击图标按钮后出现大尺寸模态框，并完整渲染现有接入说明。
- [ ] 模态框可以通过标准关闭操作退出，桌面与移动视口下无明显溢出或控件遮挡。
- [ ] 模态框底部操作栏与正文之间有清晰的上方间距。
- [ ] “复制链接”写入可直接访问该 HTML 的绝对 URL，并显示成功/失败反馈。
- [ ] “下载”触发浏览器下载同一份 HTML，文件名为 `third-party-oidc-integration-guide.html`。
- [ ] 后端仓库不再保留 `docs/third-party-oidc-integration-guide.html`，前端构建产物包含且可访问该文件。
- [ ] 前端类型检查与生产构建通过，并有针对入口、资源路径及工具栏行为的自动化回归检查。
